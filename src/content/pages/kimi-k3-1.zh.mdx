## 一句话看懂 Kimi K3.1

Kimi K3.1 被普遍视为 Kimi K3 的迭代版本。K3 于 2026 年 7 月 16 日发布，以 2.8 万亿参数成为目前规模最大的开源模型。从泄露线索看，K3.1 大概率不会推倒重来，而是沿用 K3 的分词器与对话格式，重点强化长链路智能体任务、推理效率和稳定性。换句话说，它更像一次「打磨」，而不是一代新架构。

## 从 K2 到 K3：月之暗面的迭代节奏

2025 年 7 月，月之暗面开源 Kimi K2（1 万亿总参数、320 亿激活），凭借智能体编程能力在开源社区引发广泛关注。此后 K2 系列持续小步迭代，截至 10 月中旬，月之暗面 API 仍在提供 kimi-k2.6 与面向编程的 kimi-k2.7-code。2026 年 7 月 16 日，K3 将参数规模推到 2.8 万亿，11 天后公开完整权重与技术报告。

沿着 K2 的经验看，「大版本发布 → 数月后小数点迭代」是月之暗面的惯常节奏。K3 发布已满三个月，K3.1 的时间点与这一节奏吻合。

综合来看，最硬的证据是月之暗面自己的网站代码与 API 注册表——它们说明「K3.1」这个名字在内部真实存在，但并不能告诉我们它有多强、何时上线。

## 为什么值得关注

K3 发布后，开发者最集中的反馈是三点：响应速度、推理过程的 token 消耗，以及长任务中的可靠性。如果 K3.1 能在保持 2.8T 规模能力的同时降低推理开销，开源模型在编程智能体、深度研究和长文档分析上的性价比将进一步拉开差距。券商报告与泄露配置都指向同一方向：更长、更自主的多步骤任务。

稀疏 MoE 是 K3 「大而不贵」的关键：总参数 2.8 万亿，但每个 token 只调用约 3.7% 的参数。其他官方要点：

- **注意力：**Kimi Delta Attention 与 Attention Residuals，官方称扩展效率约为 K2 的 2.5 倍。
- **数值格式：**MXFP4 权重、MXFP8 激活；完整权重约 1.56 TB，分 97 个分片，推荐 64 卡以上的超节点部署。
- **推理模式：**思考始终开启，reasoning_effort 可选 low / high / max（默认 max）。
- **固定采样：**temperature 1.0、top_p 0.95，传入其他值会报错——接入时要特别注意。
- **价格：**输入 $3、输出 $15 每百万 token，缓存命中 $0.30。

## 传闻中的新能力

- **三档推理强度：**Low 省成本，Max 保质量。不过 K3 的 API 已提供同样的三档，这未必是新功能；另有单一来源称可能新增 medium 档。
- **百万级上下文：**内部代号「Extra Long」，与 K3 的 1,048,576 token 持平。
- **智能体与多智能体协作：**配置中出现 Agent、Swarm、搜索与批处理等模式。Kimi 产品已支持 Swarm，这些开关可能只是集成工作，而非能力升级。
- **其他传闻：**网页代码中的「make3d」模式、编程专用变体等，均为单一来源。

## 对开发者意味着什么

如果 K3.1 真的沿用 K3 的分词器与对话格式，迁移成本会很低。建议现在就做好三件事：

1. **把模型 ID 做成配置项。**上线后改一行配置即可灰度切换，出问题能秒级回滚。
2. **按 reasoning_effort 分层调用。**简单分类、抽取用 low，复杂编程与研究再用 max，能明显减少推理 token 与等待时间。
3. **算清真实成本。**以 K3 价格为例：一次请求输入 2 万 token、输出 2,000 token，约 $0.06 + $0.03 = **$0.09**；若 2 万 token 的系统提示走缓存，输入部分降到约 $0.006。长提示场景务必用好缓存。

## 现在该怎么做

不必空等。K3 现已可用，你可以先在 [kimik3 工作台](/) 用自己的真实任务建立 30–100 条评测集，参考 [Kimi K3 API 接入指南](/kimi-k3-api) 与 [提示词合集](/kimi-k3-prompts)。K3.1 上线后，用同一套评测重跑，再结合 [模型对比](/compare) 与 [价格页](/pricing) 决定是否切换。

## 常见问题

### Kimi K3.1 发布了吗？

还没有。截至 10 月 23 日，官方没有发布模型卡、权重或定价。

### 什么时候发布？

报道多指向 10 月中下旬，但此前的预测已多次落空，请以官方公告为准。

### 价格是多少？

尚未公布。预告页据报显示与 K3 相同的价格，但可能只是占位。

### 从 K3 切换需要改代码吗？

据报道分词器与对话格式不变，大概率只需换模型 ID，但切换前务必先跑回归评测。

### K3.1 会开源吗？

K3 是开放权重模型，有爆料称 K3.1 也会跟进，但目前只是单一来源，尚无官方承诺。
