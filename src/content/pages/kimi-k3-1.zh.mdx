<GuideSection id="what-is-kimi-k-3-1" number="01" title="Kimi K 3.1 是什么？">

**Kimi K 3.1** 通常指月之暗面的 Kimi K3.1 系列，正式首发型号为 **K3.1 Pro**。它基于 K3 继续迭代，具备视觉理解与最高百万 token 上下文，重点面向编程、研究和多步骤任务。[官方介绍](https://www.kimi.com/en/blog/kimi-k3-1-pro)

模型负责理解与推理，具体产品提供文件、工具和工作环境。因此，实际能交付什么，还取决于你选择的入口与权限。

<GuideSection id="capabilities" number="02" title="适合用来做什么？">

- **编程：**读取项目、定位问题、修改文件并执行检查。Kimi Code 提供桌面端、CLI 和 VS Code 扩展。[产品文档](https://www.kimi.com/code/docs/en/)
- **资料研究：**跨文档提取证据、比较方案，要求逐项注明出处，把缺失信息单独列出。
- **3D 创作：**在具备相应工具的环境中描述场景与约束，生成后检查输出是否符合用途。
- **分析建模：**整理假设、计算与结论，适合处理需要反复核查的材料。

这些方向来自[官方能力介绍](https://www.kimi.com/en/blog/kimi-k3-1-pro)，实际质量仍应由你的任务验证。

</GuideSection>

<GuideSection id="get-started" number="03" title="如何开始使用？">

日常工作从 [Kimi 官网](https://www.kimi.com/) 进入；编程使用 [Kimi Code](https://www.kimi.com/code/docs/en/)；应用开发选择 [API 开放平台](https://platform.kimi.com/)。先用一个熟悉的小任务测试，再扩大范围。

开放平台型号为 `kimi-k3.1-pro`、`kimi-k3.1-pro-highspeed`；Kimi Code 使用 `k3.1-pro`、`k3.1-pro-highspeed`，请分别查阅文档配置。

</GuideSection>
