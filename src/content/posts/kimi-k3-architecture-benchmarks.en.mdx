## 1. Architecture: KDA + Stable Latent MoE

K3 only stays efficient at 3T parameters because of two structural bets. The image below visualizes the difference between KDA's hybrid linear attention and a vanilla Transformer — compression plus residual correction rather than full softmax at every step.

![KDA linear attention compression](k3-kda-attention-1785746764870.png)

### Kimi Delta Attention (KDA)

KDA rewrites the attention block with **hybrid linear attention + Attention Residuals**:

- **Linear long-term memory** — a kernel trick compresses a 1M-token context into a low-rank hidden state, dropping cost from `O(n²)` toward `O(n)`.
- **Attention Residuals** — full attention is preserved at the positions that matter, so local semantics don't get blurred.
- **Stable perplexity at 1M tokens** — the context window can stretch to **1M tokens** without perplexity blow-up, which vanilla Transformers cannot do.

### Stable Latent MoE

K3 rebuilds the MoE layer from the ground up — routing on **latent state**, not on discrete tokens:

![MoE routing — 16 of 896 experts active](k3-moe-routing-1785746767568.png)

- **896 experts** — enough capacity that each expert can specialize tightly.
- **16 active per token** — activation rate just **3.7%**, yet expressivity far exceeds a small dense model.
- **State-based routing** — vastly more stable than discrete top-k gating, which closes the train-inference gap.

Compared with K2, this combo pushes K3's overall **Scaling Efficiency up by 2.5×**.

## 4. Why this is a turning point

Kimi K3 is not an incremental upgrade — it is a hinge:

1. **No vendor lock-in** — at the same quality tier, K3 can be private-hosted, on-prem deployed, and configured with Zero Data Retention.
2. **Auditable reasoning** — model weights and inference stack are inspectable. Hallucinations and biases can be traced back to a layer.
3. **Cost curve that doesn't explode with usage** — at the same token spend, K3 runs about twice as many invocations.
